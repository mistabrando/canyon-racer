# UI narrow handoff — day/timer collision + medal wrap + tagline gap (2026-09-17)

Worker scope: N1–N3 only. Touched `src/style.css` and `src/main.ts`
(HUD/menu text + markup only). No gameplay, input, camera, ghost/share,
run-state, or course/test logic changed. `index.html` needed no edits.

## N1 — day/timer collision: hide `#day` at <=430px + pin grid placement

Chose the "hide `#day`" option: the date is already prominent in the menu
card (`#pdate`), and any shared-row form still risked touching the timer at
320px. Mobile rule is now:

```css
#day { display:none; }
#timewrap { grid-column:2; }
#best { grid-column:3; }
```

The two `grid-column` pins are the non-obvious part. `display:none`
removes `#day` from the grid entirely, so auto-placement slid `#timewrap`
into track 1 and `#best` into track 2 — measured at 390px racing: timer
flush-left at x=12, best glued at x=170, overlapping the speed readout
(`89 km/hBEST —` on screen). Explicit placement keeps the 3-column grid
(`minmax(0,1fr) auto minmax(0,1fr)`, still grid-not-flex per the CSS
comment): timer centred, `#best` at the right edge. Desktop untouched.

Measured (racing HUD, post-fix):
- 320px: timewrap 77–243 (centre 160 = viewport centre), `#time` 28px,
  `#speed` 14px ends at 243, `#best` 13px at 259–308 — 16px clear, no
  overlap, no viewport overflow.
- 390px: timewrap 112–278 (centre 195), speed ends 278, best 329–378 —
  51px clear.
- 360/430: same structure verified via screenshots + rect probes, no
  overlap, no horizontal overflow. `#day` is `display:none`, width 0.
- Timer/speed never truncate (`white-space:nowrap` kept); `#best` keeps
  `max-width:34vw` + ellipsis; 13px floor and `#msg.count`
  (`clamp(46px,13vw,78px)`) untouched.

## N2 — medal wrap: flex row of atomic pairs, separators dropped

`#ptargets` is now `display:flex; flex-wrap:wrap; gap:2px 12px;
justify-content:center`. `renderMenuTargets` / `renderFinishTargets` build
one atomic flex item per chunk (`.tpair` / `.tchunk` / `.tlabel`, all
`white-space:nowrap`); spacing comes from `gap`, and there are no `·` text
separators left anywhere in the line, so no separator can ever end a line —
wrap happens only between pairs. `sepNode()` removed (only the two
renderers used it). Per-medal colours kept (gold `#ffd75e`, silver
`#cfd8e3`, bronze `#f0a266`, times `#ffe9d2`); BEST path renders
`BEST <time> / <MEDAL|NO MEDAL YET> / GOLD <time>` as three gap-spaced
items; finish path renders `REFERENCE` / `next <MEDAL> by <time>` (one
atomic chunk) / sectors each as their own item; unknown next-target shapes
fall back to a plain text node. DOM built with textContent only, never
innerHTML (unchanged); `lastPtargetsKey` guard untouched.

Measured wrap (menu, no stored best):
- 390px: row 1 `TARGETS — · GOLD 0:33.84 · SILVER 0:37.53`, row 2
  `BRONZE 0:43.07` — bronze centred alone, no dangling separator.
- 320px: row 1 `TARGETS — · GOLD 0:33.84`, row 2 `SILVER 0:37.53 ·
  BRONZE 0:43.07`.
- BEST/finish branches: code-reviewed (same item pattern); the BEST branch
  could not be rendered headless here (no stored best; localStorage empty),
  so the integrator should eyeball it once with a saved PB.
