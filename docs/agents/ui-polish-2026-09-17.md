## What changed

**F1 — countdown size (`#msg.count` / `#msg.count.go`).**
- New single writer `setMsg(text, count, go)` in `src/main.ts`; all 13
  `#msg` writes audited and routed through it (toMenu, startWatch,
  doRespawn, startRun, finishRun, watch REFERENCE COMPLETE, countdown
  digits/READY/GO!, run→clear, STUCK / OFF COURSE / LOW GRIP / DRIFT /
  conditional clear). Non-countdown lines always clear `.count`/`.go`.
- Before: countdown digits at 17px/800, same as the idle hint.
- After: digits `clamp(46px, 13vw, 78px)`/900, `GO!`
  `clamp(52px, 15vw, 88px)`/900 (slightly larger, same family/colour).
- Reserve: `#msg` now always reserves `min-height:clamp(56px, 16vw, 92px)`
  with flex centering, so the transient never shoves `#exitfb`/`#lesson`/
  `#split` below it. Removed the old mobile-only 44px reserve (superseded).

**F2 — `#day`/timer collision.**
- `#timewrap` gets `min-width:0` (grid item may shrink), `#time` gets
  `white-space:nowrap` (a time value can never wrap mid-string).
- Mobile (`<=430px`): `#topbar` gap 8px → 10px; `#day` letter-spacing
  .05em → .04em plus `max-width:32vw` so a long
  `CANYON DAILY · SEP 17` label ellipsizes early and can never reach the
  timer; `#best` capped at `34vw` symmetrically.

**F3 — `#presult` dead gap.**
- Before: always `min-height:44px`.
- After: base `min-height:0; margin-bottom:10px`; tall reserve
  (`44px/14px`) only under `#presult.finish`, which `finishRun()` adds
  and the menu loop + share handler remove.

**F4 — medal targets.**
- Before: flat text `TARGETS — GOLD 0:33.84 · SILVER 0:37.53 · BRONZE 0:43.07`.
- After: `renderMenuTargets()` / `renderFinishTargets()` build DOM nodes
  (textContent/createTextNode only, never innerHTML): each `LABEL time`
  is a `.tpair` (`white-space:nowrap`), labels tinted per medal —
  gold `#ffd75e`, silver `#cfd8e3`, bronze `#f0a266` (all high-contrast
  on the `#201310` card), times in `#ffe9d2`. `#ptargets` line-height
  1.7 so wrapped pairs breathe. BEST path and finish path (REFERENCE
  prefix, next-target, sectors) render the same medal colours; unknown
  next-target shapes fall back to a plain text node. Flat `targetText()`
  removed (no other users). A `lastPtargetsKey` guard skips rebuilds —
  the menu branch runs every frame.

**F5 — secondary-button contrast.**
- Before → after (primaries `.modebtn.active`/`#drivebtn` untouched):
  `.modebtn` bg .10 → .16, border .22 → .38;
  `#ctrlrow button` bg .08 → .16, border .18 → .38;
  `#sharebtn` bg .14 → .22, border .3 → .5.
- Type-scale floor kept: nothing user-facing below 13px.
